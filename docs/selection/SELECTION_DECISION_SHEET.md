# Selection Decision Sheet

> **For the owner.** A practical worksheet for choosing the 25 tales (Q-411). Each entry repeats the analyst's provisional assessment and the main points from the story bucket; **every owner field is blank and is for the owner alone** (D-022). Nothing on this sheet is a selection, a ranking or a recommendation of a final list. The order is catalogue order (TC numbers), which implies no preference. Compiled 2026-11-18 by an AI session (Claude Code); not independently reviewed.

**How to use it.** Read [SELECTION_OVERVIEW.md](SELECTION_OVERVIEW.md) first. For any candidate, the linked bucket has the evidence. Suggested owner choices (use any wording you like):

- **Include in core 25**
- **Keep as reserve**
- **Do not include in core 25** (the owner may separately record it as *Supplementary — not part of the core 25*; see [SUPPLEMENTARY_MATERIAL_REGISTER.md](SUPPLEMENTARY_MATERIAL_REGISTER.md))
- **Hold pending a specific investigation** (name it; see [RESEARCH_IMPACT_AUDIT.md](RESEARCH_IMPACT_AUDIT.md))

Comparison group numbers refer to [COMPARISON_BUCKETS.md](COMPARISON_BUCKETS.md).
