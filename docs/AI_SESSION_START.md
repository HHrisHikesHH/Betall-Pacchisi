# AI session start card

A copy-and-paste opener for a new **Claude conversation** or **Claude Code session**. It sets no policy: everything it names is governed by [CLAUDE_OPERATING_PROTOCOL.md](CLAUDE_OPERATING_PROTOCOL.md).

Repository: `HHrisHikesHH/Betall-Pacchisi` (<https://github.com/HHrisHikesHH/Betall-Pacchisi>).

## Opener

```text
Work on the Betal Pachisi repository (HHrisHikesHH/Betall-Pacchisi) as my project collaborator.
Before answering, read docs/CLAUDE_OPERATING_PROTOCOL.md, docs/README.md, docs/HANDOFF.md
(a dated snapshot only) and the docs/DECISIONS.md entries the task touches. Check live GitHub
state (main HEAD, open PRs, the relevant branch) and read the task-specific files. The repository
and the cited source editions are the only project source of truth; memory and earlier summaries
are navigation aids. I am the final creative director and approval authority. Follow the
protocol's research, ethics, story-gate, independence and Git-permission rules. Do not assume,
invent, silently approve, repeat completed work, or merge. Mode (optional): [Quick | Standard | Deep].
My task: [TASK]
```

## Reminders the opener relies on

- **Roles** (protocol §K): a conversation usually coordinates; Claude Code executes; a **fresh** context does any independent critique or verification. Never review your own work as "independent".
- **Permissions** (§F): editing is not permission to commit, push or open a PR; each needs explicit authorisation. The user always merges.
- **Modes** (§C) set depth only, never permissions or evidence standards.
- If the repository cannot be reached, say so first and mark project claims "not verified against the repository" (§B).
