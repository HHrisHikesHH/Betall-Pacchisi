# Callbacks ledger

Callbacks and call-forwards between tales (D-087). Each brief reads this ledger, and each published draft updates it.

**Rules:**
- Add one only where a tale has a real use for it. Never forced, no minimum, at most two per tale.
- It must make sense to a reader who skipped the earlier tale. Add a one-clause recap.
- A call-forward never spoils what comes later.
- Wait until the reading order is fixed (D-086).
